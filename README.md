# Personal Launcher updates

Public APK releases for Personal Launcher. The application source repository remains private.

Download the signed Android APK from [the latest release](https://github.com/AtecHEvolutioN/Personal-launcher-updates/releases/latest). Newer versions can update an existing installation signed with the same key without clearing its data.

The launcher checks this repository for new releases without a GitHub account or token. With automatic downloads enabled, it downloads updates over unmetered Wi-Fi while Home is open. Each release includes the APK, `personal-launcher-update.json`, and `SHA256SUMS`. Android asks for confirmation before installation.

No source code, signing keys, account credentials, or personal app settings are stored in this repository.
